# Ish’s Design Process

A single-file, responsive interactive visualization of Ish’s nine-stage product design process and self-assessment.

## Preview locally

Open `index.html` in a browser. The page has no build step or local dependencies. It loads Manrope, Space Grotesk, and DM Mono from Google Fonts when an internet connection is available, with sans-serif fallbacks.

## Publish with GitHub Pages

1. Create a GitHub repository and upload `index.html` and this README to the repository root.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the branch containing the files and the `/ (root)` folder, then save.
4. GitHub will provide the published site link in the Pages settings.
